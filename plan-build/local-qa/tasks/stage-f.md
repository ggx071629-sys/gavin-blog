# 阶段 F：本机真实问答联调与部署交接

状态：2026-09-06 已完成；最终结果见 [F 归档](../archive/stage-f.md)。以下保留原任务范围。
返回 [主计划](../build-qa.md)。

## 工作与完成条件

1. 在本机联调真实本地 Embedding + 真实第三方 Chat，覆盖中英提问、跨语言证据、连续问答、准确引用和无证据拒答。
2. 验证 Chat 故障、Embedding 故障、Qdrant 故障、预算耗尽、断连/删除及清理行为；按既有合同展示受控结果，不能把离线演示回答当真实 Chat 成功。
3. 根据影响计划执行 provider 合同、索引集成、问答 E2E 和必要质量门禁；补测真实 Chat 路径的 API 内存、CPU 与整体延迟，修订本机容量推算。
4. 更新管理员操作说明、配置示例及架构决策，交付部署配置区间和依赖条件；证据只提交紧凑 manifest，权重、秘密、原始日志留在本地。
5. 明确本地运行模式、API 能力开关、运营 gate 和 Web 入口状态。实际生产部署单独立项处理既有资格 profile、HTTPS 和 readiness 适配；本方案不自动修改生产校验，也不将本地估算伪装为目标 runner 的签名证据。
6. 交接服务启停、模型身份检查、日志位置、索引更新、Key 更换、预算调整和回滚步骤。

完成条件：本机真实问答验收通过，完整资源估算已按真实链路修订，并完成管理员部署材料交接；不以已经上服务器作为本轮完成条件。

## 实测范围

在本机运行真实 E5 + 第三方 Chat；覆盖完整问答、故障、并发负载与运行资源。离线演示、模拟回答、单次普通 Chat 成功均不替代本阶段验收。2 核 / 4 GB 受限虚拟机实验继续跳过，不以服务器可访问作为前置条件。
