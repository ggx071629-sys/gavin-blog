## 资源结果与限制

完整资源实测：Nuxt 构建产物、API、独立 Worker、Qdrant、E5 模型五角色同时运行；41 个容量测试来源、每代 1,001 切片，完成冷启动、稳态、505 tokens 输入、查询与重建重叠及限制两个逻辑处理器后的稳态。工作集合计稳态样本中位数约 **1.99 GiB**，全程同步峰值约 **2.13 GiB**；同步私有分配峰值约 **4.55 GiB**，与物理驻留口径不同。加入规划余量与 OS/缓存预算后推算 **7–8 GiB 内存**、约 **2 个同档逻辑核热态预算**、约 **12 GiB 应用磁盘**，不是运行时实际驻留量或云端保证。原始采样有一次约 6.11 秒停顿，瞬时峰值可能漏采；Chat 路径尚未测量。详见 [容量报告](../../../harness/docs/operations/e5-retrieval-evaluation.md#2026-09-06-最终容量报告) 和 [容量 manifest](../../../harness/verification/evidence/20260906-local-capacity-measurement.benchmark.json)。历史 [早期本机测量](../../../harness/verification/evidence/20260906-local-e5-retrieval.benchmark.json) 的服务器待办保留为当时方案事实，当前后续步骤以本计划为准。

<a id="method"></a>
## 原验收与测量方法

以下数值是本方案的初始验收目标，不是已测性能或模型官方保证。

- 准备人工标注的至少 40 条正向检索问题：中文→中文、英文→英文、中文→英文、英文→中文各 10 条；另测无相关内容、术语、代码、中英混排和超长文本。
- 统计 Recall@5，整体目标不低于 0.85，各语言方向单独报告；检查召回片段及引用，不用向量余弦分数直接冒充准确率。
- 在本机同时运行 Nuxt 构建产物预览、API、独立 Worker、Qdrant 和单模型进程；不以开发热更新进程替代部署进程测量。阶段 D 不调用 Chat，API 测量仅覆盖当时实际执行路径；真实 Chat 开销在阶段 F 补测。内容库、runtime 和集合使用隔离测试数据。
- 固定模型/pipeline、语料规模、切片数、并发、请求速率和测试时长，记录本机硬件、系统与后台负载。分别采样冷启动、预热后稳态查询、查询与重建重叠三种场景；每秒记录各受测进程及其子进程的 CPU 时间增量、工作集/私有内存、整机可用内存与换页指标，同时记录延迟、队列、错误和磁盘占用。后台无关进程单列，避免将编辑器/浏览器内存误算为服务需求。
- 内存估算：同时报告同一采样时刻进程组内存峰值和各进程峰值之和；共享页可能重复计数，后者只作保守包络。以观测工作集与私有内存需求的较大保守包络为服务基线，另列操作系统/文件缓存预算，追加 `max(基线的 30%, 768 MiB)` 余量，再向上取整给出部署内存区间。30% 与 768 MiB 是本方案的规划余量，不是实测事实或平台保证；明确是否已重复计入缓存。覆盖不足时输出缺项，不能由两个进程峰值推定整套服务需求。
- CPU 估算：将进程组 CPU 秒增量除以采样区间秒数，得到占用的本机逻辑核当量；同时报告均值、p95、短时峰值和吞吐。可用 `忙碌窗口核当量 / 0.6` 给出规划核心预算参考（60% 为预留余量的假设）。这只描述本机同类核心的负载需求；不同 CPU 单核性能、虚拟化和线程调度差异要单列不确定性，不能按“16 核到 2 核”线性换算延迟或承诺云端 vCPU 性能。必要时在本机限制 CPU 亲和性/配额做敏感性对比，并注明其不等于另一款 CPU。
- 初始本机延迟目标：预热后、并发 1、32–128 tokens 查询集的 Embedding 请求 p95 ≤ 2 秒；另报接近 512 tokens 的表现、索引干扰和受限 CPU 场景。此目标不包含第三方 Chat 延迟。记录内存不足、OOM、持续换页、队列积压与失败，不通过增加 swap 掩盖容量问题。
- 磁盘估算包含模型及依赖、内容库/媒体、Qdrant、重建时新旧 generation 并存、快照和日志；按已测内容规模报告基线与增长假设。扩大语料或并发后的需求须补测，不能无限线性外推。若 FP32 本机延迟或估算需求不合适，再验证同一模型的 ONNX / INT8，重复参考向量与检索回归；优化版单独标识并重建。

完成条件：人工审核的检索结果通过，形成覆盖完整受测进程组的本机资源 manifest 和容量推算报告，明确 CPU/内存/磁盘区间、余量、负载范围、未测项及跨平台限制。**据此进入第三方 Chat 人工配置阶段，不再等待服务器或 2 vCPU / 4 GB 真机压测。** 推算完成不等于已部署或生产资格通过。
