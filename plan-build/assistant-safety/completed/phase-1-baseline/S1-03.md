# S1-03 支持材料、失败与离线评估契约

2026-09-11，完成设计核对；实现与验收属于 S2，本记录不代表功能上线。

- 选择每个 AnswerBlock 增加内部 `supports` 列表，每项含 `citation_id` 与 `quote`；quote 为本轮实际送入模型证据 body 中的非空连续原句。text 继续自然综合，不要求等同摘录。引用集合与支持材料别名集合一致，不得错绑或借前块引用；标题/heading 只描述来源，不单独证明事实。
- 正常事实块必须有材料；固定简历不可用提示无引用、无 supports。缺材料的旧预置生成结果不得绕过新检查；Python 解析可给空列表以读取旧结构，校验时拒绝。生产 strict schema 与本地 JSON schema 使用同一字段语义，模型替身同步。
- 每块最多 8 项支持材料，每项至多 1200 字符；材料进入现有 schema 输入估算与输出 token 上限，不提高预算、不增加调用。该上限是实现防止无界重复的限制，不是测试样本门槛。
- 原句核验只保证来源绑定；额外确定性检查处理已确认奖项、能力、数字/单位、否定和主体差异样例，不声称穷尽语义蕴含。无需重述来源中每个词，正常综合须保留。
- 缺失/伪造/错绑/明确不支持返回 grounding，映射现有证据不足，不公开支持材料；结构错误与截断沿用现有错误类别。保留现有最多两次生成及超时/未知结果规则，不加语义模型调用或第三次补救。
- supports 仅随现有短期 attempt.parsed_json 暂存供恢复重验；成功或校验失败终止时清除，不进 SSE、公开/管理响应、成功历史、checkpoint 或日志。不迁移已经完成的旧会话回答；旧未完成 attempt 缺材料则按新校验失败处理。
- 源码已确认生成后重新 hydrate 当前来源；仅选中并仍有效的证据可参与支持材料核验，撤销后不能用旧 quote 发布。
- 离线比较复用 S1-01 样例并补主体/否定/时间代表例。Codex 分别记录程序结果与人工证据判断，不建设评测平台，不调用配置模型。语义检查若有收益只给建议；在线接入仍需另行决定。

验收：已对照 providers 的双 schema、prompt 的 schema 预算、graph 的 attempt 恢复/重验/清除与最多两次生成路径。发现最终失败分支当前不统一清除 parsed_json，列入 S2-03 修复；对外字段不增加。无待用户决定项。
