# S1-02 自然综合与部分回答契约

2026-09-11，完成契约核对；产品实施由 S2/S3 承接，本记录不宣称已修复。

- 保留自然语言综合，每块只表达少量相关事实，citation_ids 只能支持本块，历史和前块均不能补足本块证据。
- 问题一半有据：仅生成有据部分，可在该块说明所给材料未记载另一部分；不能将“未记载”写成“没有发生”。全无依据继续使用空 blocks 的现有不足语义。
- 个人能力来自 profile/resume 或明确自述；文章主题不推断作者能力，自述使用归属措辞；冲突并列说明并分别引用，过去任职不得改为现职。
- 列举覆盖当前片段中的不同条目，不推断总数；固定简历不可用提示保留为后端确认的独立例外。
- 无效输出不发布；不在程序中任意裁掉一句再拼接剩余自然语言，以免丢失否定、归属或上下文。部分回答由生成阶段构造，整份输出统一校验。

可观察例：材料只说“自述使用 Python”，可答“公开资料自述使用 Python，所给材料未记载获奖情况”；不可答“精通 Python 且获得图灵奖”。材料“2020—2022 任工程师”只能作为过去经历。两个来源对同一事实相反时不能用其中一段包装确定结论。

验收：与 DESIGN §1/3/4/7 逐项核对；现有 SYSTEM_PROMPT 已覆盖部分回答、自述、冲突和片段限制，但缺少强制逐块材料与时间限定。S1-01 的实际漏洞交由 S2 修复；无新增测试门槛，无待答偏好。
