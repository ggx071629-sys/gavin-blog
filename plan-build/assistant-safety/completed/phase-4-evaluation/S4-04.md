## 建议

独立语义复核值得后续评估：本轮确实发现了普通关系推断和未记载经历的漏检，也发现严格规则的误拒。但 **本轮不接入在线语义模型**：尚无真实候选校验模型的可靠性、相关错误、超时、费用与延迟数据，Codex 判断也依赖材料范围与主体前提，不能按此次人工发现直接推断线上收益。保留“先离线比较、再决定接入”的已确认策略。

后续如继续提高可靠性，应以这些剩余正反例比较候选语义校验，并考察校验器也被资料指令影响、与生成器共享偏差、保守拒绝损失正常回答等变量；不自动新建任务、定时器、模型预算或发布授权。

正式依据：[逐块支持](../../../../harness/specs/archive/20260911-assistant-grounding.md)、[输入与资料防护](../../../../harness/specs/archive/20260911-assistant-defense.md)、[支持语境补修](../../../../harness/specs/archive/20260911-assistant-support-context.md)。每份归档链接 compact evidence，原始日志留本地，原 spec 保留 Git 历史。收尾仅更新计划/评审文档并运行 Harness 结构检查，不重复产品测试。
