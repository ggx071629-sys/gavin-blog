## 参数方案

以下数字是本项目拟定的工程限制，不是库默认值或已实测性能；实施时以夹具验证边界。

| 项目 | 参数与语义 |
| --- | --- |
| 触发 | 首次配置/换址事务登记待处理；由既有 fenced 索引 worker 执行；不定期检查，不由访客请求下载，不另增常驻进程 |
| 有效期（已确认） | 成功版本不按时间过期；只在首次/换址导入或手动刷新时下载；后台展示最后成功检查时间，不声称已自动跟踪原 URL |
| 手动刷新 | 显式启动一次下载检查；已有进行中任务则合并；最短 60 秒间隔，返回任务真实状态或 429/Retry-After |
| 重试 | 一次已触发操作的网络/429/5xx 暂时失败后最多追加 1、5、15 分钟重试，之后等待下一次手动刷新；Retry-After 不得被本地重试提前；非法 URL、类型、加密、解析失败不自动重试 |
| 请求 | HTTPS、443、精确可信域名配置（默认空集即不允许下载）；拒绝凭据、片段、IP 字面量、非公网 DNS 结果；每跳重新检查，最多 3 跳且目标也在可信集合；禁用环境代理、Cookie 和认证；连接到已校验地址并保留原主机 TLS/SNI，避免 DNS 检查与连接分离 |
| 文件边界 | 流式读取最多 10 MiB；仅 PDF 文件头且 Content-Type 为 application/pdf 或 application/octet-stream；不依赖扩展名和 Content-Length；拒绝压缩 HTTP 内容编码，减少解压边界 |
| 时间边界 | 连接 5 秒，单次读空闲 5 秒，含重定向的网络总截止 30 秒；DNS 也纳入总截止；解析总截止 15 秒 |
| PDF | 最多 20 页；拒绝加密，即使空密码能打开；提取为空或任一有内容页无法提取文字则失败，不悄悄导入残缺的扫描页；无 OCR，不承诺检测已有 OCR 文本的准确性 |
| 提取库 | 选 pypdf；实施时锁定兼容版本和 lockfile；按页保留文字和页码，不抓取 PDF 内嵌链接、不执行脚本/附件 |
| 解析隔离 | worker 所有的短生命周期解析子进程，无网络/数据库访问；一次一个，15 秒截止、256 MiB 进程内存上限、200000 字符结果上限；约束必须可在支持平台强制执行，否则以 parser_unavailable 失败关闭，不能用线程超时冒充资源隔离 |
| 变化检测 | 完整下载后的 SHA-256 为文件变化权威；每次操作下载有界文件并比较 hash，相同文件复用既有提取/索引；不把 ETag/Last-Modified 当文件正文摘要；手动刷新尽力要求 no-cache，仍不保证绕过 CDN |
| 失败恢复 | 一旦检查失败即暂停引用及新检索资格；成功确认同 hash 可复用保留的版本重新启用；新 hash 则先失效旧版，再解析并排队新索引；等待期间不借用旧片段 |
| 状态位置 | 现有个人资料简历 URL 下展示同步阶段、最后成功检查 UTC（前端本地显示）、错误及操作；保留“查看简历”配置 URL |

可信域名集合是部署配置，实际地址缺失不阻止夹具；未授权域名时保留 URL 字段但同步状态明确为 blocked_host，不进行下载。短生命周期解析子进程属于新增执行边界，Q1-04 spec 必须声明所有权、资源约束与平台验证；不新增服务或部署目录。

## 调查依据

- `apps/api/app/assistant_index/worker.py:run_forever` 已有循环，`_process_once_fenced` 已有 owner fence；新增首次/换址/手动请求队列并避免被重建或 outbox 长队列饿死；不调度周期检查。
- [pypdf 文字提取文档](https://pypdf.readthedocs.io/en/stable/user/extract-text.html) 说明 PDF 无可靠语义层、扫描图片不可直接提取，解析可能消耗大量内存。因此下载字节上限不能单独证明解析资源有界。
- [HTTPX 超时文档](https://www.python-httpx.org/advanced/timeouts/) 区分连接、读、写、连接池超时；工程上另设总截止，不能把 read timeout 当整个下载期限。
