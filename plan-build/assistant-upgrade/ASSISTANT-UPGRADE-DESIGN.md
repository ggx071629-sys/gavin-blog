# 问答助手改造：共识基线

2026-09-11。整理本次对话已确认的两个需求，供阶段计划引用；实现及验收状态以执行计划和机器证据为准。
未确定事项集中在第 5 节；本文件不自行确定参数、部署平台或新增验收门槛。

## 1. 范围

- 目标：让现有 RAG 能依据关于页和简历内容回答招聘访客的问题。
- 复用现有关键词与向量混合检索、证据组装、生成及引用校验，不重建助手。
- 不新增访客统计、对话监测、额外聊天留存、同意弹窗或公开简历正文页面。
- 简历采用链接导入，取代此前讨论的手工维护第二份简历文本方案。
- 前次开场白和快捷问题的独立修改指令不在本轮重新实施；发现已有修改应保留。
- 关于页与简历代码已接入并进行隔离夹具验收；实际公开简历已通过标准管线隔离导入，随后已完成实际本地库启用；未提交付费Chat问题或部署公网服务器。

## 2. 关于页

- 读取关于页已发布版本中的介绍、能力说明、当前方向、本站介绍和技术栈等适用文字。
- 只保存草稿不改变助手知识；发布、回滚触发索引更新，失效旧版本不参与新回答。
- 新索引未就绪时该来源暂不可用，其他有效来源仍可回答；不冒充已同步。
- 回答引用显示“关于 Gavin”，点击进入 `/about`；同时补齐前后端引用路径与来源类型契约。
- 提示词接受关于页明确自述作为个人事实依据，保留“不从文章主题推断能力、不夸大、不编造”。
- 当前依据：[发布入口](../../apps/api/app/routes/admin_about.py)、[发布版本服务](../../apps/api/app/about_page_service.py)、[来源投影](../../apps/api/app/assistant_index/projector.py)、[引用路径](../../apps/web/utils/assistant/allowlist.ts)。
- A-1：已发布资料可检索、可回答、可引用；草稿不可见。
- A-2：发布与回滚更新生效，旧版本失效，索引等待状态真实。
- A-3：关于页自述可作为证据，文章主题仍不能冒充个人经历或已证明的能力。

## 3. 简历

- 保留后台简历 URL 和前台“查看简历”；不新增公开正文页，不要求维护一份重复文本。
- 首次配置后由后端下载 PDF、提取文字、建立索引；模型不自行访问网址。
- 首次配置/换址自动导入，同址替换文件后由管理员“立即刷新”；不定时检查、不按时间过期，只有文件内容变化才重新解析和更新索引。
- 后台提供“立即刷新简历”，显示同步状态、最后成功检查时间及可操作的失败原因。
- 第一版只支持可提取文字、未加密的 PDF；扫描件、加密文件、解析失败不虚构正文。
- 简历 URL 被移除或更换时立即撤销旧来源资格并清理旧缓存；新版本不得与旧片段混用。
- 读取失败时其他资料仍可用；涉及不可用简历的信息明确说明，不能把旧版当最新版。
- 回答引用指向后端绑定的简历 PDF；不允许模型任意拼接外部来源 URL。
- 读取仅限配置的可信地址，约束文件大小、超时和重定向目标；具体规则在第 5 节收敛。
- 不保证绕过服务器/CDN 缓存，也不承诺替换 PDF 后毫无延迟。
- 简历不展示为正文网页，但接入公开助手后内容可能通过回答披露；只接入允许公开使用的版本。
- 当前依据：[简历 URL 字段](../../apps/api/app/profile_service.py)、[后台资料](../../apps/web/pages/admin/profile.vue)、[查看入口](../../apps/web/components/ProfileCard.vue)。
- R-1：链接正文真实导入，相关问题有依据且引用打开对应 PDF。
- R-2：未变文件复用结果，变化后更新，清空/换址停止使用旧来源。
- R-3：刷新与同步状态真实，下载和解析失败有明确结果且不影响其他有效资料。
- R-4：可信地址、文件限制、重定向与不支持的 PDF 类型按确定的契约处理。

## 4. 共同约束与适用验收

- 每轮仅将相关片段加入现有证据预算，不无条件附带完整关于页或简历。
- 本地正文缓存不等于模型输入免费；本地 E5、现有费用/Token 上限和有限历史策略保持。
- 保留认证、CSRF、同源消费、默认关闭、运行资格和删除/过期防止迟到写入的边界。
- 后台刷新/状态与前台引用使用现有组件风格，不扩大为页面重设计。
- 视觉仅沿用[统一规范](../studio-ui/design/README.md#统一规范)中适用的设置行、反馈、双主题、手机与键盘要求；不复制全站验收矩阵。
- C-1：两类新来源与现有资料共同检索，引用可靠且片段受现有预算约束。
- C-2：相关后台操作与前台引用接通真实契约，成功、等待和失败状态可区分。
- C-3：回归受影响的问答、来源失效、会话与配置边界；按 [Verify](../../harness/workflows/verify.md) 选择精确检查，不新增全量发布门禁。
- C-4：真实外部文件/供应商检查与隔离夹具结论分开，缺少实际条件如实记录，不自动付费或宣称生产就绪。

- 实际简历链接已提供，标准下载/解析及隔离导入验证通过，结果见阶段四Q4-03归档。
- 简历PDF与正文版本已由内容SQLite持有，替换/清空按不可复用版本清理，沿用内容备份；Qdrant仅派生向量，不新增部署目录。
- 2026-09-11 用户确认：检查失败即暂停简历证据，恢复成功后启用；新版本失败不使用旧版。
- 用户确认：允许后端保存并提供版本化 PDF 快照引用，换址/清空撤销旧快照访问；保留原“查看简历”入口，不新增正文网页。
