- 对应设计稿[交互检查](design/design-qa.md#交互与响应式检查)中的标题必填、新建、预览、发布确认、保存冲突和错误恢复。
- 八个入口按各自设计验证；历史页不得因原型只演示快照而移除既有差异与回滚能力。

- 适用验收遵循既有保存合同；不为本轮追加自动发布、编辑器重写或新的版本机制。
