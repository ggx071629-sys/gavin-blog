# F2-01 · 复现输入丢失并确定临时状态修复边界

状态：完成。运行：`.run/site-functional-fixes/20260912-01/`。

## 事实

- 真实 PATCH：修改网站说明触发 `PATCH /api/v1/admin/about-page`，用路由拦截暂缓放行。
- 根因确认：`save()` 写入 `page.value = updated` 触发 `watch(page)` → `assignForm()` → `tagDrafts.value = content.capabilities.map(() => '')`，把尚未提交的标签输入整体清空。
- 关联缺口：`moveItem(form.capabilities, …)` 与卡片删除只改领域数组，不移动/删除对应草稿，草稿会落到错误领域。

## 关键决定

- 区分“服务器工作副本刷新”与“自动保存回声”：只有前者重建草稿，回声只同步已提交字段。
- 草稿保持按领域索引跟随：排序与删除同时移动/删除草稿，不新增服务端字段。
