# F2-02 · 实施保存结果与临时输入的状态协调

状态：完成。

## 变更

`apps/web/pages/admin/about.vue`：
- 新增 `syncFromServer(content, resetDrafts)`：服务器刷新重建草稿，回声只裁剪/补齐草稿长度。
- `save()` 在写入 `page.value` 前递增 `pendingEcho`，`watch(page)` 消费该计数判断是否回声。
- 新增 `moveCapability` / `removeCapability`，同步移动或删除对应草稿。

## 关键决定

- 不做“每次保存后重建全部草稿”，避免再次清空未提交输入。
- 不新增服务端字段，草稿仍为纯前端状态；预览与发布路径继续重建草稿。
