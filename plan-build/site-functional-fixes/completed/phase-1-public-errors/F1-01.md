# F1-01 · 核实隔离环境、复现 I004 并建立修复规格

状态：完成。运行：`.run/site-functional-fixes/20260912-01/`。

## 事实

- 隔离环境可用：Playwright `webServer` 启动 `apps/api/scripts/run_e2e.py`（8100）与 Nuxt dev（3100），使用临时 SQLite 与媒体目录。
- 复现（首页→文章，`**/api/v1/articles*` 注入 503）：地址变为 `/articles`，H1 仍是首页标题，`.error-stage` 不存在，重试按钮 0 个。
- 控制台：`[Vue warn] Unhandled error during execution of setup function` 与 `[Unhandled rejection] Error: 上游服务暂时不可用`，栈经 `useApiFailure` 进入 `pages/articles/index.vue` setup。
- 根因：Nuxt 根组件客户端 `onErrorCaptured` 只在错误的 `fatal`/`unhandled` 为真时渲染错误页；`useApiFailure` 初次 setup 抛出的错误两者皆无，于是成为未处理拒绝，旧页面继续显示。

## 关键决定

- 采用既有全站错误页而非新增页面级错误块：服务端失败已是该呈现，客户端与之对齐即为最小修复。
- 只在客户端标记 `fatal`，服务端继续抛出，保持既有 4xx/5xx 语义。
- 不预先宣称其余 `useApiFailure` 消费者全部复现。
