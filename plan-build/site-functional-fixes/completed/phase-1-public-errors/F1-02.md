# F1-02 · 实施首次页面加载失败与恢复修复

状态：完成。

## 变更

- `apps/web/composables/useApiFailure.ts`：客户端把初次 setup 失败标记为 `fatal`，让 Nuxt 根组件渲染既有错误页；服务端保持抛出。
- `apps/web/error.vue`：错误页站内入口改为 `clearError({ redirect })`，避免清除前错误页一直覆盖后续路由。

## 关键决定

- 修改共享错误处理而不改各页面，符合共享行为一致；不改服务端状态码语义。
- 错误页重试仍复用 `reloadNuxtApp({ force: true })`，未引入重试策略或超时。

## 边界

- 未新增页面级错误块，未改变 404/401/403/429 映射。
- 其余消费者只继承共享修正，未逐一复验（记录为剩余风险）。
