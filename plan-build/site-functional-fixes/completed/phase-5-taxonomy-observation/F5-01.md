## 关键决定

- 未复现即未复现：不把单次 pending 归因为产品缺陷，也不把“本次通过”当作已修复。
- 不新增全站超时、重试策略或永久遥测来“消除”观察记录。
- 记录下一次需要的证据：真实出现 pending 时的浏览器请求 ID、开发代理日志与 API 访问日志三方关联，或可重复的复现步骤。
