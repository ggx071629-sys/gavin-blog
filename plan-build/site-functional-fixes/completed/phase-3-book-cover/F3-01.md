# F3-01 · 核对媒体地址契约并复现封面保存失败

状态：完成。运行：`.run/site-functional-fixes/20260912-01/`。

## 事实

- 媒体库「使用 URL」经 `resolvePublicUrl` 保留站内相对地址，返回形如 `/api/v1/media/14/webp`。
- 读书编辑器封面输入为 `type="url" pattern="https?://.+"`，`WritingWorkspace.validate()` 用原生约束校验，因此相对地址被拒并显示 http(s) 专属文案。
- 服务端 `BookNoteCreate/Update.cover_url: HttpUrl | None` 同样拒绝相对地址（422）。
- 既有契约：个人名片头像已允许受限站内媒体路径 `ProfileMediaAvatarPath`。

## 关键决定

- 沿用既有站内媒体路径约定（存相对地址，保持可迁移），不放宽到任意相对路径或非 HTTP(S) 协议。
- 共享写作台新增可选字段级文案覆盖，而不是改写通用分类文案。
