## 页面与实际行为

| 页面 | 实施内容 |
| --- | --- |
| 个人名片 `/admin/profile` | 姓名、定位、简介先行，头像、技能与联系随后；表单与预览对应，去掉预览内无依据的 Live 显示。保存、冲突、公开可见性和离页保护保留。 |
| 栏目与标签 `/admin/taxonomy` | 每类资源列表优先，表单位于辅助列，手机单列；编辑将键盘焦点送到名称，失败保留条目与输入，使用中的栏目不能删除。 |
| 媒体库 `/admin/media` | 真实缩略图和筛选在前，上传与外链登记在后，DOM 与视觉顺序一致；管理页准确命名复制 Markdown/URL。剪贴板失败提供可选择的原文，单项移除、恢复、加载更多和批量失败可见。 |
| 内容工具 `/admin/content` | 回收站在前，导入、导出独立分区；导入草稿提供编辑入口，导出有等待、成功、失败和重试，回收站操作防止重复提交。 |
| 助手运营 `/admin/assistant` | 部署能力、悬浮入口、管理员请求与实际准入分别显示；本地观察、索引、失败任务与三类费用分区，手机每个金额有标签。保留未知、原因码、过期快照、确认、版本和资格边界。 |

## 原型与真实能力的差异

- 不提供原接口没有的媒体引用次数、反向定位到某篇编辑器、媒体详情编辑或资源文件永久删除。复制引用后可粘贴到原编辑器，三类编辑器仍可直接选择已有媒体。媒体移除保留历史链接，可以恢复；外链失效风险沿用原说明。
- 上传有内容去重，相同字节可能返回既有媒体及其原 Alt，并不创建第二条。不同验收资源使用不同文件字节，防止误把去重当作上传失败。
- 栏目和标签仍只有既有维护能力；栏目变更按现有公开 taxonomy 和发布关系更新，不新增计数接口或自动发布。
- 导入始终创建草稿；现有 Markdown ZIP 导出不等于全站数据库、配置与媒体的完整灾备方案。导入失败仍依赖原接口的事务边界。
- 助手页只读本地事实，不实时探活供应商或 Qdrant。启用、停用、重建、重试与切换调用原接口；缺少运行时资格时准确显示阻塞，UI 完成不赋予生产公开资格。
- 默认关闭的验收环境可以验证命令接收或拒绝，不能证明未运行 Worker 已完成重建，更不能报告云端效果或实际供应商账单。
