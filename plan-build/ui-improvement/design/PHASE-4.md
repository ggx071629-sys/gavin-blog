## 业务边界与差异

- 正文与设置在 768px 起并列，767px 以下用两个明确的区域按钮切换；正文内部 Markdown/预览所有宽度均为单实例切换，避免双份长内容。设置切换使用 `aria-pressed` 按钮组，支持 Tab 与 Enter/Space。
- 编辑主操作跟随页面滚动；短视口低于 560px 时取消 sticky，避免遮住正文与错误字段。列表只显示 API 已提供字段；没有新增全库检索、状态筛选或总数接口，不把原型示例控件迁为假操作。
- 新建页仍先创建草稿再进入自动保存编辑器，尚未创建时明确离页/刷新提醒。新建页接入已有 MarkdownMediaField，媒体资源先写隔离媒体库，发布前补齐 Alt；取消草稿不会自动删除已上传的共享媒体。
- 自动保存只更新工作副本；失败保留当前输入并允许显式重试。发布与站内离页仍等待最新快照完成，冲突不覆盖服务器版本。浏览器强制关闭或确认刷新仍会丢失未保存输入，提示不声称已持久化。
- 文章未填完的参考资料继续排除在自动保存载荷之外；同时显示准确的未保存提示，并要求补齐或移除后才能离开/发布。刷新有提醒。外部参考失败与字段失败不会伪装成内容冲突。
- 已发布文章单独预览读取后台工作副本，公开页面继续使用不可变发布快照。项目与读书保留编辑器内预览；原接口没有独立版本历史，不制造入口。
- 登录此前已符合本稿安静双栏/手机单列方向，本阶段保留其产品布局并回归认证与失败状态；资源运营页面与公开助手不改造。

## 实施中发现的问题

- 第一次无特权 Playwright 执行完成断言后未能正常回收 Windows 子进程，手动结束日志确认由本次运行创建的 Web/API PID；后续在允许回收自身进程的环境执行，不访问开发数据库。
- 视口立即从 767 调至 1024px 时 Chromium 有短暂旧宽度/新侧栏混合布局，原即时断言误判 216px 溢出。改用有界等待布局稳定后检查，稳定布局不允许任何横滚；同时收紧工具带尺寸。
- 复用公开可复制代码后，后台深色预览行号未继承公开限定的代码主题 token，axe 检出 3.97:1；补齐后台限定行号 token，保持原门槛。
