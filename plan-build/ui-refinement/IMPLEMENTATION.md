# 工程设计稿 UI 落地

设计来源：`site_engineering_design_preview.html`。在工作区已有蓝图风格修改上继续实现，原 HTML 保持不变。

## 范围

公开首页、文章列表、正文阅读、项目、读书、归档、搜索和关于页。保留现有 API、发布快照、筛选与分页、SEO、认证、助手开关及键盘交互。本次只调整视觉结构与展示文案，不增加业务操作或数据合同。

- 896px 公开索引轴与页眉页脚对齐，40px 网格、双主题、Space Grotesk / Noto Sans SC / JetBrains Mono 使用已有自托管字体。
- 首页声明在上，图谱与真实名片按 1.32:1 并列；窄屏顺序堆叠。栏目选择、重置、错误重试、独立栏目与文章链接仍可用。最近文章使用双列卡片。
- 文章显示栏目、日期、阅读时间、摘要与标签；手机多栏目仍局部横滚，避免压低正文。
- 项目首条突出、其余双列；书籍采用当前页在读高亮与双列卡片，阅读状态全部来自原数据。
- 归档使用年轴与边框条目；搜索输入与结果以独立面板组织；正文引用及章节分隔统一。
- 不复制设计稿预览控制台、名片模式选择器、示例文章数量、Live 在线宣称、项目评级或虚构封面。淡色装饰编号使用 aria-hidden SVG 保留，不作为可读正文。

## 验证

类型检查与 ESLint 通过。25 个相关浏览器用例经修复复验均通过：about-index、archive-index、articles-index、books-index、home-atlas、projects-index、public-reading、search-states。长内容用例覆盖 320、390、639、640、768、1024、1100、1101、1280、1440px 及双主题 WCAG A/AA；另手动验证无栏目首页的连续英文长标题换行。原始截图与 trace 仅保存在被忽略的 `.run/` 和 `apps/web/test-results/`。未运行发布级全量门禁，未更改生产配置或提交工作区已有修改。

### 运行边界

验收使用 `run_e2e.py` 的临时 SQLite 与测试登录身份，不连接开发或生产数据库。完整首次回归暴露浅色在读标签对比度不足，修正后 public-reading 的 4 个用例复验全部通过；一次路由加载用例在复验中也通过。Windows 上 Playwright 托管服务的退出回收挂起，因此用例结果按逐项输出记录，不声称取得 Harness 隔离 evidence 或发布级通过证明。原始失败 trace 保留在本机，不纳入提交。

参考 HTML 的外部 Tailwind 脚本在本机不可用，视觉核对使用项目已安装的 Tailwind 编译临时副本；原稿无修改。截图在 `.run/ui-v2/review-*.png`，阅读页多视口截图在 Playwright 本机输出目录。

## 宽屏留白调整

用户确认以本地 3101 运行页面为准，希望减少左右留白。公开索引页、首页和页眉页脚由固定 896px 改为 `min(1600px, 92vw)`；手机仍保持原有 24px 内边距，正文阅读宽度不变。实测七个公开页面在 320/390/768/1280/1536/1920/2560px 无横向溢出。1920px 视口主体宽 1600px（含内边距）；截图和几何测量保存在忽略的 `.run/ui-v2/wide-*`。

宽屏卡片高度同步：桌面文章卡片使用 `clamp(184px, min(15vw, 28svh), 264px)` 最小高度，内边距 24–40px、标题 24–32px；短屏限制卡片增高，长内容仍自然撑开。首页、项目和读书的网格卡片同步增加桌面最小高度与内边距。手机规则保持原样。实测文章页 390×844、1280×600、1536×864、1920×1080、2560×1440 无横向溢出；1920 宽屏三张卡片高度均为 264px。

## 知识路线恢复（2026-09-08）

按用户明确要求保留知识路线，不做主题汇总：根节点“我的笔记”通过可见分支连接领域、最新文章。移除汇总统计，领域和文章分别提供真实导航。悬停、焦点、点击或 Enter/Space 突出对应路线；选择后才提供“查看全部路线”。手机采用纵向连接布局。沿用最多三个领域、每栏最新一篇与原有请求上限，不推断文章先修关系。此前栏目多篇方案已撤回。

工作区验证：home 四项单元测试、ESLint、直接使用 assistant-dev 生成配置的 vue-tsc 通过。320/390/768/1440px 双主题无页面横溢，390/1440px 图谱 WCAG A/AA 扫描无违规；键盘选择与清除通过，真实文章 href 已核对。原始截图与结果在忽略的 `.run/ui-v2/knowledge-route-*`；未作为正式 Harness close 证据。
