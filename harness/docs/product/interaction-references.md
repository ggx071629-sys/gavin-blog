# 交互参考

## 知识路径聚焦（2026-09-08）

用户要求：记录截图中的聚焦交互动效，供后续设计参考。此记录不代表实施请求或已批准的行为规格。

来源：用户在当前对话提供的截图 `codex-clipboard-52dd5334-abd9-444b-be9c-28d6e6d153b5.png`；原图位于本机临时目录，长期查阅以本段文字描述为准。

### 截图可确认的视觉状态

- 采用从左到右的关系图：根节点“我的笔记” → 领域卡片 → 最新笔记卡片，中间以曲线连接。
- “云服务器 → 配置SSL”这条路径处于强调状态：根节点到领域、领域到笔记的连线均为亮蓝色；两张关联卡片使用蓝色描边和浅蓝底色。
- 另一条“Agent开发 → deepseek接入codex”路径仍完整可见，连线和边框较淡、卡片为白底，保留整体知识结构。
- 强调覆盖整条关联路径，而非只突出单张卡片；两条路径的位置与结构保持稳定。
- “浏览领域”“阅读笔记”是分别呈现的导航入口；底部提示为“选择一个领域，点亮它的知识路线”。

### 后续设计意图与待定项

记录的核心意图：聚焦某个领域时，同时突出它与根节点、关联笔记之间的关系，让用户一眼追踪知识路线。

单张静态截图不能证明触发方式、动画过程或时间参数。悬停、点击、键盘焦点是否触发，离开后是否恢复，默认是否选中，切换时的时长、缓动与连线绘制顺序，均待实际设计时确认。

候选实现方向（建议，未定案）：连线颜色、卡片描边与底色同步平滑切换；避免移动或缩放造成阅读位置跳动。若采用悬停预览，需同时定义键盘和触屏的等效操作，并区分路径选择与链接跳转。减少动态效果偏好下保留即时聚焦反馈；非当前路径仍须清晰可读。

范围：仅新增可检索的参考文档和生成索引，不改变产品代码、运行时行为或 Harness 规则。

## 全站公开卡片应用（2026-09-08 后续授权）

用户随后明确要求全站每个卡片采用此效果，写作台所有页面除外。下列约定落实该请求，取代上文尚未定案的普通卡片交互建议。

- 视觉：原地出现主题色细轮廓与 5% 主题色强调层，浅色蓝色、深色继承绿色主题；不使用卡片上浮、大阴影或缩放。原文字、导航和按钮保留。
- 鼠标：仅精细指针且支持 hover 时进入/离开平滑切换；复用 `--ee-motion-fast`（180ms），只过渡装饰层 opacity，使用 ease。
- 键盘：卡片自身或内部控件获得可见焦点时即时点亮，保留原焦点环。展示卡片不新增按钮语义、点击行为或 Tab 停靠点。
- 触屏：按压时即时反馈，释放后不保留模拟悬停；图谱仍保留既有显式点击选择。减少动态效果时即时切换。装饰层不拦截事件。
- 嵌套：当前最内层卡片反馈，外层不跟着整体点亮；图谱是明确例外，领域与关联笔记仍沿知识路径联动。
- 隔离：`/admin` 及其全部子路由（包括登录、编辑、新建、运营、工作副本预览、修订和错误页）不启用新效果；按路由更新 HTML 标记，涵盖客户端导航、共用组件及 Teleport 助手卡片。

覆盖清单：

| 页面 | 卡片 |
| --- | --- |
| 首页 | 图谱容器、根节点、领域与笔记节点、个人名片、最新文章、空态卡片 |
| 文章 | 列表卡片、桌面/移动目录、相邻文章、相关文章、反链卡片 |
| 项目 | 主推项目、列表卡片、详情关联笔记、目录及反链 |
| 书籍 | 当前在读、书目卡片、详情目录及反链 |
| 关于 | 名片、能力领域、近期动态条目、本站说明、技术栈小卡片、联系方式 |
| 搜索与归档 | 搜索面板、结果与状态卡片、归档文章条目 |
| 公开助手 | 欢迎、示例问题、来源、提示、数据说明、清除确认卡片 |
| 公开错误页 | 错误内容和恢复操作卡片 |

普通文字、正文代码与图片、标签、页眉页脚导航不作为卡片。新增卡片应显式声明 `data-focus-card`，由 `usePublicCardFocus` 和 `public-card-focus.css` 统一处理；写作台复用带标记的组件也不会启用这套样式。
