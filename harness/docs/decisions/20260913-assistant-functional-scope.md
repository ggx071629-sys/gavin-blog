# 问答助手功能收敛

2026-09-13 用户要求：“实体手机和读屏不需要验证去掉，plan目的应该是改造好问答助手保证跑通而不是做很多验证”。

- 删除实体手机和人工读屏的待办、验收表及阻塞项；这是范围取消，不记为通过，不生成完成归档。旧结果和已归档证据保留历史。
- 计划目标是修复回答错误与误拒，并跑通页面提问→真实模型→校验→SSE→追问→刷新恢复。Q5-02与Q5-04共用一次真实链路核对，不另开设备或可访问性验收矩阵。
- 测试服务于修复：针对实际失败保留必要回归及数字、否定、主体、限定反例；复用已有有效检查，不重复全量测试，不新增指标门槛、验收阶段或额外材料任务。题集作为诊断和真实模型核对工具，不将题量或检查数量当作进展。
- 已有人工题集复核材料可供参考，独立人工未执行仍如实注明，不因本次取消手机/读屏而伪造人工复核结论。
- 沿用累计200次、2元上限及原失败账本；本次范围调整没有恢复未知调用或扩大费用授权。Q6继续取消。
- 只修改本计划范围与当前状态，不修改产品运行代码、既有安全保护或仓库公共验证政策。
