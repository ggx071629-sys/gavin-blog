# 账号管理安全边界

SQLite 凭据记录是认证事实来源，配置只负责首次初始化；迁移只通过 Alembic。改密、邮箱恢复与终端恢复均在串行事务内更新哈希、版本并撤销全部会话/挑战。重开事务必须清 ORM identity map 缓存，避免在途 SMTP 回调读取外部重置前版本。

邮件用固定服务器邮箱和独立秘密 HMAC；发送先预留持久配额、锁外 SMTP、版本复检后激活。发送失败或结果未知不退款、不自动重发、不输出提供商异常。终端恢复不依赖邮件。参数、风险和完整协议见 [账户设计](../../../plan-build/account-management/ACCOUNT-MANAGEMENT-DESIGN.md)。

2026-09-11 用户恢复第三、四阶段并明确授权向本机配置邮箱发送隔离验收邮件。写作台页面直接消费生成类型，密码表单与会话撤销复用既有控件；浏览器响应注入、真实 HTTP 加邮件替身、真实 SMTP 投递分开记录。真实密码验收使用独立迁移数据库，日常凭据保持；收取与验证码消费未证实前不得完成 A4-02 或关闭 spec。
