# 账号管理安全边界

SQLite 凭据记录是认证事实来源，配置只负责首次初始化；迁移只通过 Alembic。改密、邮箱恢复与终端恢复均在串行事务内更新哈希、版本并撤销全部会话/挑战。重开事务必须清 ORM identity map 缓存，避免在途 SMTP 回调读取外部重置前版本。

邮件用固定服务器邮箱和独立秘密 HMAC；发送先预留持久配额、锁外 SMTP、版本复检后激活。发送失败或结果未知不退款、不自动重发、不输出提供商异常。终端恢复不依赖邮件。参数、风险和完整协议见 [账户设计](../../../ACCOUNT-MANAGEMENT-DESIGN.md)。

2026-09-10 用户将本次执行范围收敛到第二阶段；页面实施与真实邮件验收未启动，不将后端替身测试当端到端或真实投递证据。
