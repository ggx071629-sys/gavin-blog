# 取消部署及线上验证

2026-09-12 用户明确要求：“不需要验证部署，去掉部署线上相关的验证计划”。此决定替代本轮此前“Q6 保留目标环境与生产资格阻塞”的范围安排。

- 从知识问答缺口修复计划删除原 Q6 阶段及 D6 验收安排，包括目标环境与部署选择、部署资格适配、目标网络与权限核验、线上持续负载、真实目标恢复、上线结论和发布验收。
- 本计划保留 Q1—Q5，以 Q5-05 汇总质量结论收尾。目标环境与生产资格不再是本计划的前置、阻塞或完成条件。
- 本地功能、运行保护、浏览器与可访问性、当前内容和实际模型质量及费用评测继续按原适用范围执行；Q4-02已在后续用户指令下恢复；Q4完成情况由主计划及验收归档记录。
- 这是取消待办，不是验收通过；不生成 Q6 完成归档。已完成任务记录与原审查报告保留历史事实，以本决定解释旧记录中的后续生产安排。
- 不修改运行代码、生产启动保护、仓库既有发布政策或资格验证工具，不执行部署或公开启用。需要部署时另行明确范围。

当前入口：[知识问答缺口修复计划](../../../plan-build/assistant-gap-closure/PLAN.md)。

2026-09-12 后续恢复指令曾要求保留“Q6生产资格阻塞”，用户随后再次澄清“Q6不是已经取消了”。以最新澄清为准：Q6阶段、生产资格验证与部署均不在本计划内，不作为前置、待办或阻塞；只陈述未开展生产验证，不作生产资格结论。Q5实际质量和未验证事项继续保留。
