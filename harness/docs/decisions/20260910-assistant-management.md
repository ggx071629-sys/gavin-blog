# 问答助手管理执行与预算

用户已确认第二版管理设计并授权完整实现。真实入口为 `/admin/assistant`，概览承担公开启停、费用与同步，试问独立成页，高级维护容纳重建、切换与全局停止。

管理员试问复用公开助手的检索、模型、租约、输出复核与计费流程；认证由管理员会话和两层 CSRF 绑定，Cookie、会话 HMAC 上下文和执行 epoch 独立。普通公开关闭仅撤销公开执行。紧急停止和索引切换撤销两种执行，恢复锁、清理熔断与运行资格始终优先。管理员登录不会自动恢复执行资格。

内容库新增每日总预算策略和调用预留表，作为 API 与独立 Worker 的共同费用权威。部署中原有分类预算继续生效；总预算初值和可编辑上限取三个部署分类上限的最大值，不相加，也不提高已有费用授权。人民币金额使用整数 micro-CNY，修改需要版本匹配。

运行库准入之前先提交内容库的总额预留，运行库提交之后再同步确定结算。跨库窗口失败时保留原日预留，不凭缺失记录退还余额；结算只增不减并拒绝再次发送已结算调用。API 启动先导入当天旧运行账本，Worker 在当天导入标记产生前不发送付费批次。此选择牺牲故障当天的一部分可用额度，换取不重复消费与不超额。

索引付费批次必须为下一次有界问答保留额度；不足时进入预算等待，预算上调可唤醒等待任务。删除、撤回与清理不依赖付费预留。恢复内容备份后当天总预算锁定；上一个内容 schema 的备份仍可验证、迁移后恢复，不通过新空运行库清除当日保护。

公开布局只读取不创建会话、不调用供应商的可用性端点。可用性综合部署与运营开关、运行资格、恢复保护、回答分类预算和总预算；活动页面最长每 30 秒重新检查，读取失败隐藏入口，隐藏标签页停止轮询。实际准入仍由服务端逐次核验。

历史同步任务成功仅说明当次修订已处理，不能证明当前索引已包含最新内容。管理页分页展示任务和可核实的修订状态；未知供应商调用不会被普通重试按钮再次发送。
