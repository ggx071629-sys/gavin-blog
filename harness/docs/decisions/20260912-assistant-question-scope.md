# 题型与证据边界

2026-09-12 Q4-01 源码审阅结论；本决定是实施范围，不代表后续实现或真实模型质量已验收。

| 题型 | 可承诺范围 | 证据不足时 |
| --- | --- | --- |
| 单文档深问 | 当前有效公开片段支持的事实；只有明确指向当前页面才提升该页候选 | 告知未覆盖部分，不把片段当全文 |
| 跨源比较 | 分别引用每个来源，保留冲突和限定语 | 只能回答有支持部分，不能补造缺失一方 |
| 项目等清单 | 枚举已召回且被支持的条目 | 明示片段范围，不能推定完整库存 |
| 全站全量/总数 | 当前没有库存覆盖证明，暂不承诺 | 明确完整性未核验，建议限定来源或范围 |
| 最新/当前全局比较 | 发布更新和事实有效时间未在证据元数据中形成比较证明 | 明确时效未核验；历史角色不能升级为当前角色 |
| 无答案 | 仅在无有效相关证据时缺证据；格式/支持失败另分类 | 不能把生成失败声称为资料不存在 |
| 需澄清 | 服务端识别有限中英指代；上一有效回答恰有一个可匹配来源时用标题/路径辅助检索 | 对象不唯一、序号无法映射或已过期时先询问具体对象，不发模型请求 |

# 选定实施

- Q4-02：展示已发布 About.statement 和 editorial_topics；在来源卡显示每个引用的服务端章节/页码，并使编号跳到相应定位。无可用章节时明确需在来源中查找；不公开模型 supports 原文。保留正文TTL、撤销、版本及路径白名单。
- Q4-03：有限指代使用上一有效回答的来源定位信息，重新检索、复核当前公开版本；原回答只帮助找对象，不作为新事实。显式换题不拼接旧问题；不明确对象返回既有终态通道中的专用澄清代码，前端显示独立提示。最多四轮和短TTL不变。
- Q4-04：只有明确页面指代或已解析来源才提升当前页；全站完整性/时效请求提供专用未核验提示，普通局部事实与不声称完整的清单继续走证据问答。保留未支持的全量统计和全局新鲜度，不伪装为已实现能力。
- Q4-05：跨来源/冲突、章节/页码、草稿或撤销来源、有限多轮及边界提示完成当前版本离线回归；实际质量仍在 Q5 测量。

# 未选方案与依据

事实：hydrate 只接纳当前公开版本和有界片段；现有来源轮转改善覆盖但不能证明全量。Evidence 无独立发布日期/事实有效期，history 查询会无条件拼接旧问题；About 投影包含页面未显示的两个字段，sources 按路径去重使多个章节不易核查。

本轮选择有限确定性解析与页面优先条件。暂不引入在线查询改写模型、通用语义重排或父文档扩展：尚无独立对照证明收益，增加调用或上下文会挤占既有100次/2元预算；重排也不能产生缺失的库存覆盖/时效证明。单篇深问仍可能因片段预算遗漏，不宣称通用长文问答已解决。

局限：规则不能识别所有自然语言指代或复杂比较。澄清表示对象未确定；部分回答表示只有部分事实受支持；操作失败表示没有可信结果。这些状态不混用。用户随后[取消部署及线上验证](20260912-assistant-deployment-validation-scope.md)，生产资格不再构成本计划阻塞。
