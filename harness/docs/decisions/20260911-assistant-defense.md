# 有限输入规则与资料边界

安全术语本身不授予权限，也不单独触发拒绝。规则检查执行/泄露意图的代表性短语，保留实际凭据、工具请求、来源 URL 的既有约束。技术上下文中的凭据字段名允许讨论，明确密钥赋值不豁免。匹配时处理全角和不可见分隔，原始问题不因此改写；现有双向控制字符拒绝保持。

检索及恢复资格复核同时检查标题、heading、正文。已知执行指令的历史对不送入生成提示；普通历史仍在不可信分区，仅帮助指代，不能支持事实。用户可以指定主题、语言和长度，不能通过自称管理员/开发者/审计员改变规则。教程代码是待解释资料，不能执行。

此决定不引入在线分类器或语义服务，不增加工具权限或调用预算。原句绑定继续遵循[支持材料决策](20260911-assistant-grounding.md)。有限短语规则仍会漏检，也可能误拒引用完整攻击句的文章；离线模型替身只证明代码边界，不能证明真实模型服从或抗注入能力。
