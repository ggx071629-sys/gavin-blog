# 已复现缺口的有限修复

数字按独立数值与紧邻单位核对，不再依赖中文不适用的单词边界。输出与支持材料使用相同的完整句切分，保留逗号及限定语；个人断言和依赖、因果代表句式必须匹配当前支持上下文。技术共现不能据此推出依赖，材料未记载的作者经历不能放行。

about、profile、resume 的句首“我／本人”可转述为“作者自述”，保留否定、时间和整句内容；不替换第三方人名或嵌套引语，不把自述升级为客观认证。普通技术综合和明确缺项的部分回答继续允许。

仅完整的“文章／教程解释某段引文为何危险”等明确解释句式，在指令扫描视图中豁免引文；原始文本仍用于凭据检查，引文之外的执行请求继续检查。相同规则用于提问、证据及历史筛选，裸引号和安全话题词不能单独获得豁免。

这些规则修复已复现样例，不是通用语义证明。未列举的数字单位、关系改写、教程表达仍可能漏检或误拒；没有引入在线裁判、外部调用或新权限。原有逐块来源绑定、完整支持上下文与来源资格边界保持，参见[支持材料决策](20260911-assistant-grounding.md)和[资料防护决策](20260911-assistant-defense.md)。
