# 全站问答范围

用户明确要求：问答助手回答的是本站公开页面所有的内容，而不是某一种内容。

个人资料、关于页、公开简历、文章和项目等公开页面都是可检索证据。问题分类只能帮助定位相关信息，不能把全站助手变成某类资料专用助手，也不能用个人资料替换已召回的相关文章和项目。

回答应覆盖当前问题中有证据的各个要点，必要时跨页面整合，保留来源、主体、时间、否定和限制条件。个人技能自述、文章介绍的方法、项目明确记录的实践需区分；写过某个主题不等于熟练掌握或有对应工作经历。

“全站范围”不等于每次塞入所有页面、每次强制引用所有来源，亦不表示对尚未收录或同步失败的页面已经验证覆盖。质量验收需分别检查收录、召回、预算保留、要点覆盖与事实支持，不能以返回成功或引用存在代替回答正确全面。

此约束由用户直接确认。本地 Harness 文档不随业务发布；测试、诊断产物同样不进入业务提交与部署。
